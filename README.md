Amazon Sales Data Dashboard (Power BI)-----

This repository contains a Power BI dashboard built to analyze Amazon sales data. The purpose of the dashboard is to summarize key business metrics and make it easier to understand sales and profit patterns across different categories, regions, and time periods.





Overview----

The dashboard provides a consolidated view of Amazon’s sales dataset. It includes multiple visuals that help break down sales performance, profit trends, and order behavior. 
The goal of the project was to turn raw sales records into a clear and interactive dashboard that highlights useful business insights.


Dataset Information----

The dataset includes common sales-related fields such as:

Order ID

Order Date

Country / Region

Product Category and Sub-Category

Sales

Profit

Quantity

Shipping Mode

Customer Segment

The data was cleaned and prepared inside Power BI using Power Query, after which custom DAX measures were created to support analysis.



Key Insights and Features----

Sales and Profit Summary
A high-level view showing total sales, profit, quantity sold, and overall performance metrics.

Category and Sub-Category Analysis
Helps identify which product categories drive revenue and which ones have lower profitability.

Regional Analysis
Shows how different regions and countries perform in terms of sales and profit.

Time Trend Analysis
Monthly and yearly breakdowns that help identify seasonality or growth patterns.

Customer Segment Breakdown
Shows which customer groups contribute the most to sales and profit.

Interactive Filters
Users can filter by year, region, category, segment, shipping mode, and more to explore specific parts of the data.
